PulseTransit collects and archives real-time data from Santander's TUS bus network to enable delay analysis and predictive modeling. Currently, the project provides a live dashboard showing scheduled routes and stops, with automated data collection running in the background. Future development will integrate real-time vehicle positions and ETA predictions into the dashboard, ultimately training ML models to improve upon official arrival estimates.

Key Features

  • Real-Time Collection: 2-minute ETA updates and hourly GPS positions via Cloudflare Workers
  • GTFS Integration: Route geometries, stop metadata, and scheduled timetables from NAP
  • Interactive Map: Live vehicle positions with route shapes and stop-level predictions
  • Historical Dataset: Deduplicated estimaciones and posiciones stored in Cloudflare D1
  • Delay Analytics: Framework for computing predicted vs. actual arrival deviations

Development Phases

Phase 1: Data Collection Infrastructure ✅ Completed February 2026
Automated pipeline collecting real-time GPS positions and ETA predictions via Cloudflare Workers, storing deduplicated data in D1 with GTFS static feed integration for route geometries and stop metadata.

Phase 2: Live Dashboard ✅ Completed February 2026
Interactive map visualization showing scheduled routes, stops, and service patterns with custom domain deployment on Hugging Face Spaces.

Phase 3: Real-Time Integration 🚧 In Progress

  • Display live vehicle positions on map with route matching
  • Show real-time ETA predictions at stop level
  • Compute and visualize delays (predicted vs. scheduled arrival)

Phase 4: ML-Enhanced Predictions 📋 Acquiring training data

  • Train models on historical GPS + ETA data to predict arrival times
  • Integrate weather features from Meteomat for delay forecasting
  • Compare ML predictions against official TUS estimates
