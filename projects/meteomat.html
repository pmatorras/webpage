Meteomat: Weather Forecast Dashboard

🌦️ Launch Dashboard GitHub Repository 🤗 HF Space


Standard weather apps hide forecast uncertainty by showing single-value predictions, leaving users unsure about forecast reliability. Meteomat addresses this by visualizing ECMWF ensemble forecasts with probabilistic confidence ranges—answering "how confident is this forecast?" instead of just "what's the forecast?" Built as an interactive dashboard with global coverage (focused primarily on Europe), the application is served through Cloudflare at meteo.matorras.com and deployed on Hugging Face Spaces with automatic fallback mechanisms.

Key Features

  • Ensemble Uncertainty: 10th/50th/90th percentile bands from 51 ECMWF ensemble members
  • Multi-Variable Forecasts: Temperature, rainfall, wind speed/direction, humidity
  • Interactive Map: Click any European location or search by city name
  • 7-Day Horizon: Hourly resolution forecasts
  • Custom Visualizations: Plotly with JavaScript theming and smart tick generation

Technical Architecture

Data Pipeline: Real-time ECMWF IFS ensemble forecasts are fetched via the Open-Meteo API based on user-selected coordinates, processed to extract percentiles (10th/50th/90th) from 51 ensemble members, and rendered as interactive Plotly charts with custom JavaScript theming in Streamlit.

Custom JavaScript Integration:Implemented smart_ticks.js for dynamic x-axis formatting that adapts tick intervals to zoom level (hourly < 24hrs, daily > 5 days), automatically detects Streamlit themes, and enforces axis constraints to prevent zooming beyond data bounds.
