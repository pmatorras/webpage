Meteomat: Weather Forecast Dashboard

🌦️ Launch Dashboard GitHub Repository 🤗 HF Space


Standard weather apps hide forecast uncertainty by showing single-value predictions, leaving users unsure about forecast reliability. Meteomat addresses this by visualizing probabilistic forecasts with confidence ranges - answering "how confident is this forecast?" instead of just "what's the forecast?"

v2 brings three major upgrades: HRES blending combines the 51-member ECMWF ensemble with the higher-resolution HRES run for sharper best estimates while keeping uncertainty bands intact; a marine tab exposes swell and wind wave height/period and sea surface temperature; and a horizon picker lets you choose between 24 h, 72 h, and 7-day views. The app is served through Cloudflare at meteo.matorras.com and deployed on Hugging Face Spaces.

Key Features

  • HRES + Ensemble Blending: Sharper best estimates by blending the 51-member EPS with the 9 km HRES run, while retaining full uncertainty bands (50/50 when rain is expected, 75/25 otherwise)
  • Ensemble Uncertainty: 10th/50th/90th percentile bands from 51 ECMWF ensemble members
  • Marine Tab: Swell and wind wave height/period, sea surface temperature - inspired by growing up checking surf conditions on the Cantabrian coast
  • Multi-Variable Forecasts: Temperature, rainfall, wind speed/direction, humidity
  • Forecast Horizon Picker: Switch between 24 h, 72 h, and 7-day views
  • Worldwide Coverage: Click any location on the globe or search by city name
  • Custom Visualizations: Plotly with JavaScript theming and smart tick generation

Technical Architecture

Data Pipeline: Real-time forecasts are fetched via the Open-Meteo API based on user-selected coordinates. Weather variables pull both the 51-member ECMWF EPS and the single-run HRES, which are blended before rendering. Marine variables come from the ECMWF Wave Model. Percentiles (10th/50th/90th) are computed on the fly and rendered as interactive Plotly charts with custom JavaScript theming in Streamlit.

Custom JavaScript Integration:Implemented smart_ticks.js for dynamic x-axis formatting that adapts tick intervals to zoom level (hourly < 24hrs, daily > 5 days), automatically detects Streamlit themes, and enforces axis constraints to prevent zooming beyond data bounds.

Development Phases
