Financial-Sentiment-LLM

A multi-task Large Language Model (LLM) pipeline that fine-tunes FinBERT to detect financial sentiment nuances across news, social media, and retail investor forums.

Key Results

Metric Value Notes
Overall Accuracy 85.0% Across all three datasets
Macro F1-Score 0.84 Balanced precision/recall
News Accuracy 92.1% FinancialPhraseBank
Forum Accuracy 80.2% +15% vs Baseline (FiQA)

Data Sources

The model is trained on a diverse mix of financial text to ensure robustness across different domains.

Dataset Source Type Role in Training
Financial PhraseBank Professional News Captures formal financial reporting language (e.g., "Earnings rose by 5%")
Twitter Financial News Social Media Handles informal, short-form commentary and reactions.
FiQA (Forums) Retail Discussion Regression Target: Teaches the model sentiment intensity rather than just categories.

Technical Approach: Multi-Task Learning

Standard classifiers often fail on retail forums (like Reddit/FiQA) because they miss the nuance between "slightly negative" and "very negative."

Why Multi-Task FinBERT won: This project implements a dual-head architecture sharing a single BERT backbone:

  • Head 1 (Classification): Predicts Negative/Neutral/Positive for standard news.
  • Head 2 (Regression): Predicts a continuous sentiment score for forum posts.

This forces the model to learn sentiment intensity, resulting in a +15% accuracy boost on complex forum data compared to standard classification baselines.


Project Roadmap

This project is being developed in three phases:

  • ✅ Phase 1: Baseline – Established single-task benchmarks (Completed Dec 2025).
  • 🔄 Phase 2: Optimization (Current) – Implementing LoRA/QLoRA and Multi-Task architectures.
  • ⬜ Phase 3: Integration – Deploying sentiment scores as features into the Financial-ML Equity Selection System.

Quick Start

The project is built with PyTorch and HuggingFace Transformers. It includes a custom CLI for training and evaluation.

# Clone and setup
git clone https://github.com/pmatorras/financial-sentiment-llm.git
cd financial-sentiment-llm
python -m venv .venv
source .venv/bin/activate
pip install -e .
# Train the multi-task model
python -m finsentiment train

# Evaluate performance
python -m finsentiment evaluate


For advanced configuration and flags, see the GitHub Repository.
