MacroEconomics Dashboard

The MacroEconomics Dashboard is a lightweight tool that fetches, cleans, and visualises key macro indicators, such as inflation or GDP, for selected countries using a reproducible Python workflow. Interactive Plotly/Dash charts let visitors explore trends and compare countries over time, both in the form of a time series, as well as interactive maps with options to generate static HTML plots for fast embedding or run the full dynamic app on a hosting service. Designed for clarity and extension, it can be run locally to update data, export charts, or served as a live dashboard, as shown below.

Please note that the dashboard may take a moment to load on first access, as it is hosted on a service with periodic initialisation delays.
