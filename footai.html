FootAI Dashboard

footAI is an end-to-end football analytics system that combines Elo rating calculations with machine learning to predict match outcomes across Europe's top five leagues. Built on historical data from 2015-2025 spanning Spain, Italy, England, Germany, and France, it features a reproducible Python workflow that downloads raw match data from football-data.co.uk, computes dynamic Elo rankings with multi-season decay and promotion/relegation transfers, engineers ML features (rolling statistics, odds movement, league context), and trains RandomForest models achieving 50.5% accuracy on three-class prediction (home win, draw, away win) and 37.4% draw recall on tier-1 leagues (~8,000 test matches). The modular CLI supports multi-country training, temporal cross-validation, and automated result logging, with optional interactive Plotly visualizations and Dash dashboard deployment. Designed for transparency and extensibility, the pipeline handles data acquisition, feature engineering, model training, and evaluation in a single unified framework.

Please note that the dashboard may take a moment to load on first access, as it is hosted on a service with periodic initialization delays.
