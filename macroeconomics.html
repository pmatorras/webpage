Macro Economics

  • The MacroEconomics Dashboard is a lightweight tool that fetches, cleans, and visualizes key macro indicators—such as inflation and GDP—for selected countries using a reproducible Python workflow. Interactive Plotly/Dash charts let visitors explore trends and compare countries over time, with options to generate static HTML plots for fast embedding or run the full dynamic app on a hosting service. Designed for clarity and extension, it can be run locally to update data, export charts, or served as a live dashboard
