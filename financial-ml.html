Financial‑ML

GitHub repository that ingests S&P 500 constituents, downloads monthly prices, engineers features, and trains baseline classifiers to predict 12‑month outperformance vs a benchmark.

Optionally fetches fundamentals from public filings and persists tidy, time‑aligned datasets for downstream modeling.

What this builds

  • Symbols and monthly adjusted closes for S&P 500 tickers plus a benchmark, saved as tidy CSVs for the full or test universe.
  • Selected quaterly fundamentals (assets, liabilities, equity, revenues, net income, EPS, shares) normalized as point‑in‑time series.
  • Binary label of 12‑month forward excess return vs benchmark, with out‑of‑fold predictions for analysis.

Tools and infraestructure

  • Python ≥ 3.10, pandas, numpy
  • scikit‑learn pipelines and TimeSeriesSplit
  • yfinance, requests, pyarrow
  • CLI entrypoints for info, fundamentals, and train

Features used

Market behaviour

  • r1 (1m return), r12 (12m return), mom121 (12m − 1m momentum), vol3 (3m std), vol12 (12m std) — short/medium trend and risk regime signals for momentum/volatility framing.

Fundamentals

  • Value/profitability (Book‑to‑Market, ROE, ROA, Net Margin), balance‑sheet risk (Leverage), investment intensity (Asset Growth), dilution (Net Share Issuance), plus a size control.

Models and evaluation

  • Models: L2/L1 logistic regression with scaling and class weighting, plus a Random Forest baseline (trees use passthrough scaling by design).
  • Splits: Expanding backtest via TimeSeriesSplit with 5 folds and approximately 36‑month test windows to respect time ordering.
  • Metrics and outputs: AUC per fold; out‑of‑fold predictions saved with date, ticker, y_true, y_prob, y_pred, fold, and model for downstream analysis.

Quick start

# Editable install (recommended for development)
          python -m venv .venv
          source .venv/bin/activate  # Windows: .venv\Scripts\activate
          python -m pip install -U pip 
          pip install -e .

          # Refresh constituents and prices (test mode)
          python -m financial_ml --test -d info --newtable --newinfo

          # Fetch fundamentals (test mode shown)
          python -m financial_ml --test fundamentals

          # Train baseline models
          python -m financial_ml train
